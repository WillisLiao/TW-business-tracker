# data/

Published monthly revenue, written only by the automated pipeline (see README.md).

- `revenue/YYYY-MM.json`: one file per month, one company per line, amounts in thousand NT$ as filed.
- `companies.json`: names and industries from the exchanges' company profiles.
- `status.json`: last run, per-source health and queued alerts.

The git history of this folder is the public record of what was published and when.
